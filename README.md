# 图书调研信息管理平台

## 前言

欢迎来到图书调研信息管理平台项目，本项目旨在提供一套高效、易用的信息管理解决方案，帮助用户实现图书调研相关工作的数字化、智能化。以下是本项目的详细说明，希望能帮助您更好地了解和使用本平台。

## 内容介绍

图书调研信息管理平台是一个基于Java语言的Web应用，采用Spring、Springmvc、MyBatis等主流框架进行开发。该平台主要包括图书信息管理、调研项目管理、用户管理等功能模块，满足各类用户在图书调研过程中的需求。通过本平台，用户可以方便地实现图书信息的录入、查询、修改和删除，同时支持多用户协同工作，提高工作效率。

## 技术介绍

- 语言：Java
- 使用框架：Spring、Springmvc、MyBatis
- 前端技术：JS、Vue、CSS3
- 开发工具：IDEA/Eclipse
- 数据库：MySQL 5.7/8.0
- 数据库管理工具：phpstudy/Navicat
- JDK版本：jdk1.8
- Maven：apache-maven 3.8.1-bin
- 前端环境：Node.Js 12\14\16
